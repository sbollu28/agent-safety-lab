Independent AI Security Research Engineering

Agent Safety Lab

Surya Bollu · Network Security, Infrastructure Automation, Agent Safety

A reproducible offline prototype demonstrating independently enforced safety checks on AI-proposed network changes.

Research question

How should untrusted agent-generated action proposals be validated against scoped authorization and trusted network policies?

What is implemented?

A structured Python guardrail, a deliberately weak keyword baseline, 18 synthetic test cases, and CI unit tests. The demonstration does not invoke an LLM or change any network device.

Explore source code and tests · Read methodology and limitations

Research directions

Prompt injection, tool-use authorization, scoped approvals, change safety, human oversight, fail-closed decisions, and adversarial evaluation.

This is an independent research prototype, not a production safety guarantee or employer disclosure.
